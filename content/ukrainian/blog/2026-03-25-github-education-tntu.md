## Воркшоп успішно завершено!

25 березня 2026 року в читальному залі ТНТУ №2 відбувся воркшоп з GitHub Education. Захід зібрав здобуваів та викладачів, які дізнались про можливості Student Developer Pack та безкоштовний доступ до професійних інструментів розробки.

### Що було на воркшопі:

- Презентація **Student Developer Pack** — набір з понад 100 безкоштовних інструментів
- Практичний гайд з реєстрації та отримання доступу
- Огляд кар'єрних можливостей через GitHub
- Індивідуальні консультації для учасників

Дякуємо всім, хто долучився! Слідкуйте за анонсами наступних заходів.
