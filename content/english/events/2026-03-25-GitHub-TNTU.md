## About the Event

We invite students and teachers of TNTU to a GitHub Education workshop!

### What you will learn:

- **How to get the Student Developer Pack** — free access to professional development tools
- **GitHub Copilot** — AI assistant for writing code
- **GitHub Codespaces** — cloud development environment in your browser
- **GitHub Classroom** — tool for teachers to manage assignments
