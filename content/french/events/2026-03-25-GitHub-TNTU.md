## À propos de l'événement

Nous invitons les étudiants et enseignants de TNTU à un atelier GitHub Education!

### Ce que vous apprendrez:

- **Comment obtenir le Student Developer Pack** — accès gratuit aux outils de développement professionnels
- **GitHub Copilot** — assistant IA pour écrire du code
- **GitHub Codespaces** — environnement de développement cloud dans votre navigateur
- **GitHub Classroom** — outil pour les enseignants pour gérer les devoirs
